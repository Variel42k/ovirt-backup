# Проверка сжатия и выбора алгоритма задания

Дата: **30 октября 2026 года**. Проверялась рабочая копия проекта с изменениями,
базовый коммит `240d089`. Рабочий стенд не использовался, перенос и питание
реальных ВМ не выполнялись. Код нейросетевого сжатия не устанавливался.

## Результат проверок

| Проверка | Результат |
|---|---|
| `go test ./... && go vet ./...` | Успешно: 38 пакетов с тестами, включая API/store/scheduler с отдельной реальной PostgreSQL 17 |
| Новые кодеки | Побайтовое чтение, шифрование, повреждение, усечение, несжимаемые данные, уровни 1/3/9 |
| Смешанная цепочка | zstd → gzip → S2 → LZ4 → Brotli успешно читается одним читателем |
| Размер чанка | Дополнительно проверен чанк 4 МиБ + 137 байт для LZ4/Brotli и отказ при распаковке сверх ожидаемой длины |
| `npm run build` | Проверка типов и production-сборка прошли |
| Playwright | 10 сценариев desktop/mobile прошли: LZ4/Brotli, повторное открытие, наследование, none и неприменимость к Proxmox |
| govulncheck | 0 находок уровня импортированного пакета/вызова; 1 предупреждение уровня модуля, указанное ниже |

Go: **1.27.3**, Linux amd64, `CGO_ENABLED=0`. Новые зависимости:
**github.com/pierrec/lz4/v4 4.1.33** и **github.com/andybalholm/brotli 1.2.7**.
Проверки выполнены через Docker Desktop. PostgreSQL размещалась в tmpfs
отдельного контейнера и использовалась только для тестов.

При подготовке проверок прямой доступ к Google Go proxy/sumdb давал таймауты.
Для контейнеров использовался `GOPROXY=https://goproxy.cn` и штатный
`GOSUMDB=sum.golang.org`; проверка подписанной базы и контрольных сумм модулей
не отключалась. Эти переменные не записаны в постоянные настройки проекта.

## Локальное синтетическое сравнение

Команда: `go test ./internal/backup -run TestAdditionalCodecs -bench BenchmarkChunkCompression -benchtime=150ms -count=1`.

CPU: AMD Ryzen 5 9600X. Один искусственный повторяющийся буфер **1 МиБ**, уровень
**3**, один запуск теста. Измеряется encode с SHA-256 без шифрования, диска и сети.
Ниже не приведены результаты на образах реальных ВМ; обобщать их на другие
данные или использовать как обещание пропускной способности нельзя.

| Алгоритм | Скорость encode МБ/с | Хранимый размер от исходного |
|---|---:|---:|
| zstd | 1609,90 | 0,31% |
| gzip | 824,60 | 7,13% |
| S2 | 1450,79 | 8,56% |
| LZ4 | 1198,51 | 12,42% |
| Brotli | 254,20 | 4,71% |
| none | 2315,84 | 100,00% |

Сырые результаты, включая аллокации: `codec-benchmark.txt`.
Для выбора по RTO нужно отдельно измерять восстановление и загрузку приложения.
В текущей выборке zstd оказался и плотнее, и быстрее новых кодеков; это результат
данного искусственного буфера, а не универсальное ранжирование алгоритмов.

## Ограничения сканирования

govulncheck **1.7.0**, источник `vuln.go.dev`, дата базы **27.10.2026 21:16 UTC**.
Результат разобран из JSON-сообщений, а не выведен из exit code процесса.

Осталось [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932): не поддерживаемый
`golang.org/x/crypto/openpgp` в модуле x/crypto 0.58.0. Импорта пакета или
достижимого вызова сканер не нашёл; исправленная версия в базе не указана.
Находка не исключалась фильтром. Для новых LZ4/Brotli находок нет в использованной
базе. Это не полный аудит поставки, ОС или проверка БДУ ФСТЭК.
