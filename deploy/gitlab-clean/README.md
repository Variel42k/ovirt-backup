# jhvirt-gitlab-clean

Хелпер анализа и очистки истории репозиториев GitLab. Ставится **внутрь ВМ с
GitLab**, а не на сервер копий: служба вызывает его по SSH.

- `jhvirt-gitlab-clean` — сам хелпер (forced command, работает от имени `git`);
- `setup.sh` — установка: пользователь, правило sudo, ключ службы.

```bash
# публичный ключ службы — тот, чью приватную часть вы вставите в подключение
sudo sh setup.sh --pubkey jhvirt-gitlab-clean.pub                 # только анализ
sudo sh setup.sh --pubkey jhvirt-gitlab-clean.pub --allow-clean   # копия ВМ: разрешить очистку
```

Анализ читает историю и ничего не меняет — так хелпер можно ставить и на
рабочий GitLab. Очистка переписывает историю и необратима: `--allow-clean`
указывают только на копии ВМ, поднятой из бэкапа. Для очистки нужен пакет
`git-filter-repo`, а службы `puma` и `sidekiq` должны быть остановлены.

Полный порядок работы — в `docs/OPERATIONS.md`, раздел «Очистка истории
репозиториев GitLab».
