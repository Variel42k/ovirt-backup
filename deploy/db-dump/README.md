# Хелпер логических дампов СУБД

Ставится на хост PostgreSQL или MySQL/MariaDB — на ВМ или физический сервер.
Служба копий подключается к нему по SSH ключом, который разрешает только
команду хелпера; паролей СУБД служба не получает.

| Файл | Назначение |
|---|---|
| `jhvirt-db-dump` | хелпер: `probe`, `list`, `dump`, `globals`, `restore` в новую базу |
| `setup.sh` | пользователь, ключ с `restrict,command`, роль в СУБД, настройки |
| `db-dump.conf.example` | `/etc/jhvirt/db-dump.conf`: восстановление, сокет, исключения |

```bash
sudo sh setup.sh --pubkey jhvirt.pub --postgresql
```

Публичный ключ — пара к приватному, который вводится в интерфейсе службы
(**Дампы СУБД → Хост СУБД**). Затем в интерфейсе: «Получить» ключ хоста,
сверить отпечаток, сохранить и нажать «Проверить».

Подробно — раздел «Логические дампы СУБД» в
[docs/OPERATIONS.md](../../docs/OPERATIONS.md).
