## Что проверено

После подготовки warm-групп независимая проверка через клиент oVirt подтвердила
работающие источники и выключенные цели. После переключения она подтвердила
выключенные источники, состояние целей `up`, фактический выбранный хост,
домен и размер дисков, число дисков, RAM, vCPU, топологию CPU, BIOS и отсутствие
сетевых интерфейсов.

При откате проверено удаление целей и возврат исходников к исходному состоянию:
`down` для холодных прогонов, `up` для warm-прогонов. В холодной последовательной
группе отдельно проверены приостановка и возобновление ожидающей задачи без
создания её цели. Неверный хост заблокирован проверкой плана; повтор одной ВМ
в запросе отклонён с HTTP 400; исходные ВМ при этих проверках не изменились.

Предварительные автоматические проверки этой сборки: `go vet ./...`, полный
`go test ./...` в Linux с изолированной PostgreSQL, сборка Vue/TypeScript,
**26 проверок Playwright** на настольном и мобильном экранах с API-заглушками.
Они покрывают форму, множественный выбор, оба режима, обе очереди, выбор хоста
и доступных ему доменов, права, блокировки, сбои и восстановление очереди после
рестарта. Журнал Go сохранён в [go-tests.log](go-tests.log).

На установленном интерфейсе дополнительно проверены открытие формы в исходном
списке ВМ, выбор хоста и домена из действующего инвентаря, история и окно деталей
реальных холодной и warm-групп на экранах 1440×900 и 390×844. Браузерные запросы
изменения данных блокировались; ошибок JavaScript не обнаружено.

## Границы проверки

Холодные реальные прогоны начинались с уже выключенных источников.
Штатное выключение работающих источников физически проверено в warm-прогонах;
холодный сценарий с работающим источником покрыт автоматическим тестом.
На выбранном целевом подключении был один доступный хост в состоянии `up`;
размещение при выборе между несколькими работающими хостами здесь не проверялось.
Физический параллелизм проверен на двух ВМ; нагрузка из большего числа ВМ
не запускалась. Рестарт приложения проверялся автоматическими тестами.

Состояние `up` подтверждено API oVirt. Работоспособность гостевого приложения,
сети, Windows, UEFI, лицензий и побайтовое совпадение исходного и целевого
дисков в эту приёмку не входили. Сетевые настройки проверены браузерными
и серверными тестами с заглушками.
